## How to run the tic-tac-toe in android
1. Start Android Studio
2. Open project
3. Start Medium Phone AI 36.1
4. Run `flutter devices`. It will list the connected devices.
5. One of the connected devices will be `emulator-5554`
6. Run `flutter run -d emulator-5554`
